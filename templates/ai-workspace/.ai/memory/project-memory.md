# Project Memory

Project memory is curated, validated, reusable knowledge for this project.

It is not a scratchpad. It is not a dump of chat history. It is not a place for protected material, raw outputs, logs, or generated artefacts.

---

## Memory Rules

Add knowledge only when it is:

- validated
- reusable
- project-specific
- safe to store
- useful for future tasks

Do not add:

- guesses
- unverified assumptions
- one-off debug notes
- raw external responses
- protected material
- generated artefacts
- temporary experiment notes

Temporary notes belong in:

- `.ai/scratch/`
- `.ai/research/`
- `.ai/sandbox/`
- `.ai/experiments/`
