# Web App Preset

Recommended for frontend or full-stack web applications.

## Defaults
- Project class: web-app
- Risk tier: medium to high depending on exposure
- Preferred mode: full for externally exposed apps
- Typical commands:
  - install: project-defined
  - lint: project-defined
  - test: project-defined
  - build: project-defined
  - smoke test: build plus app startup or route verification

## Focus areas
- auth and session handling
- input validation
- output encoding
- dependency and supply chain review
- environment separation
