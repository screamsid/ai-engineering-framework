# Validation Testing Skill

## Purpose

Ensure implementation matches:

- acceptance criteria
- expected behaviour
- framework requirements
- operational expectations

## Core Checks

- acceptance criteria verification
- expected output validation
- workflow behaviour verification
- rollback awareness
- edge-case review
- regression awareness

## Required Outputs

- validation_summary
- expected_vs_actual
- confidence_gate
- known_gaps

## Required Validation

- compare outputs against requirements
- identify incomplete behaviour
- identify missing validation
- verify acceptance criteria coverage

## Stop Conditions

- acceptance criteria unmet
- expected behaviour missing
- rollback path unclear
- validation evidence missing

## Confidence Guidance

Lower confidence when:

- acceptance criteria are ambiguous
- validation coverage is partial
- rollback behaviour is untested
- important edge cases were skipped

## Candidate Lessons

This skill should propose memory candidates when:

- validation repeatedly misses the same issue
- requirements ambiguity causes defects
- a reusable validation approach improves quality
- acceptance criteria patterns repeatedly fail
