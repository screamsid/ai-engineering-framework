# Operating Model

## Summary
The framework separates stable rules from project-specific configuration and live task state.

## Layers

### 1. Framework layer
Stable rules, workflow, roles, and standards.

### 2. Project layer
Project profile, architecture notes, backlog, and audit log.

### 3. Working state layer
Current story, branch, blockers, risks, and next action.

## Why this matters
This reduces repeated context and helps different agents operate consistently without relearning the same project rules each time.
