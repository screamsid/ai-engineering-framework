# Human Task Entry Template

## Task ID

Example:

```text
STORY-003
```

---

## Task Type

Examples:

- python-automation
- infra-automation
- framework-design
- security-tool

---

## Objective

Describe what should be achieved.

Example:

```text
Build a secure inventory summary CLI for infrastructure reporting.
```

---

## Scope

List what IS included.

Example:

- CLI entry point
- structured logging
- smoke tests

---

## Out of Scope

List what must NOT be done.

Example:

- web UI
- database persistence

---

## Risk Level

Allowed values:

- low
- medium
- high
- critical

---

## Confidence Score

Range:

```text
0-100
```

---

## Validation Requirements

Examples:

- smoke-test
- validation-test
- security-review

---

## Stop Conditions

Examples:

- confidence_below_threshold
- unresolved_security_risk
- missing_acceptance_criteria

---

## Escalation Preferences

Examples:

- reviewer-check
- security-review
- release-manager
