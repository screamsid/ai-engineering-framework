# Standard Mode
Use for most internal software and automation projects.

## Active roles
- planner
- builder
- reviewer
- security-reviewer
- git-manager

## Minimum controls
- planning required
- smoke testing required
- deeper testing where logic changes
- security review required for triggered areas
- git hygiene required
- audit log required
