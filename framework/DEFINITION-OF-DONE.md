# Definition of Done

A story is only done when all of the following are true:

- requirements are understood and met
- scope has been respected
- code and config changes are minimal and maintainable
- relevant documentation is updated
- audit log is updated
- smoke tests pass
- deeper tests pass where required
- security review has been completed where required
- review findings are resolved
- git history is clean and traceable
- tags are created where required
- backlog items discovered during work are recorded separately
- handoff or completion notes are written clearly
